# Omniva Shipping Module for PrestaShop 8.x and 9.x

Omniva shipping module for PrestaShop that provides courier and parcel terminal shipping integration with Omniva services across Europe.

> **Using PrestaShop 1.6 or 1.7?** Use the [Omniva Shipping v2.x module](https://github.com/mijora/omniva-prestashop-1.6-1.7) instead.

## Requirements
- PrestaShop 8.0 or newer
- PHP 7.4 or newer

## Installation
1. Download the `omnivaltshipping.zip` file from the link above
2. In PrestaShop admin, go to **Modules** → **Module Manager**
3. Click **Upload a module** and select the downloaded ZIP file
